## Project Description

This project focuses on implementing and analyzing different algorithms using Java. It explores algorithm behavior, time and space complexity, iterative and recursive approaches, sorting techniques, and execution performance.

The main purpose is to apply fundamental concepts of algorithm design and analysis through practical implementations and experimental evaluation.

## Objectives

- Implement algorithms using Java.
- Analyze algorithmic complexity using Big O notation.
- Compare iterative and recursive solutions.
- Implement different sorting algorithms.
- Measure and compare execution times.
- Apply unit testing to verify code correctness.

## Project Activities

### Activity 1: Algorithmic Complexity Analysis

Implementation and analysis of algorithms with different time complexities:

- **O(n):** Linear array summation.
- **O(n²):** Element comparisons using nested loops.
- **O(log n):** Repeatedly dividing a number by two.

The number of operations and algorithm behavior are analyzed using different input sizes.

### Activity 2: Iteration and Recursion

Implementation of iterative and recursive solutions for:

- Factorial calculation.
- Array element summation.
- Finding the maximum value in an array.

Both approaches are compared in terms of results, operation counts, and execution times.

### Activity 3: Sorting Algorithms

Manual implementation of the following sorting algorithms:

- Bubble Sort.
- Selection Sort.
- Insertion Sort.
- Shell Sort.

### Activity 4: Benchmarking and Performance Analysis

Evaluation of sorting algorithm performance using:

- Different input sizes.
- Sorted, reverse-sorted, random, and nearly sorted arrays.
- Multiple executions to calculate average execution times.
- Comparison counting.
- Performance tables and graphs.
